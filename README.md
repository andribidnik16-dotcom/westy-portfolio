# WESTY Portfolio — розгортання на Render

Це окрема копія лише сайту-портфоліо. Бота, токенів і локальної бази даних у ній немає.

## Завантаження

1. Створи GitHub-репозиторій і завантаж у нього вміст цієї папки.
2. У Render обери **New → Blueprint** та під’єднай GitHub-репозиторій.
3. Render прочитає `render.yaml` і створить вебсервіс. Після завершення розгортання відкрий адресу, яку покаже Render.
4. Адмінка буде за адресою `https://адреса-твого-сайту/admin/`.

## Доступ до адмінки

Після розгортання створи суперкористувача командою `python manage.py createsuperuser`
у Shell свого сервісу Render, якщо ця функція доступна для обраного тарифу.
Потім увійди в `/admin/` з цими обліковими даними. Доступ у цій адмінці мають
лише активні суперкористувачі.

## Важливо про безкоштовний тариф

Безкоштовний вебсервіс Render може засинати за відсутності відвідувачів.
Також його локальні файли, зокрема SQLite-база, не є постійним сховищем:
дані профілю, проєкти та обліковий запис можуть зникнути після перезапуску
або повторного розгортання. Тому цей безкоштовний варіант підходить для
попереднього перегляду, але не для надійного зберігання вмісту адмінки.
Для постійних даних під’єднай постійну базу даних і сховище або обери хостинг
із постійним диском.

Не додавай до GitHub `.env`, паролі, секретні ключі чи бази даних.
